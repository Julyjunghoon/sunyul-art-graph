선율이의 그림 그래프 - 사용법
================================

1) 그림 추가하기
   "6살에 만든 작품" 폴더 안에 선율이 그림 사진을 넣으세요.
   (jpg, jpeg, png, webp, gif 파일을 지원해요)

2) 업데이트하기
   "그림_업데이트.bat" 파일을 더블클릭하세요.
   창이 뜨고 "그림 O개를 찾았어요" 라고 나오면 완료된 거예요.

3) 확인하기
   "index.html" 파일을 더블클릭해서 브라우저로 열거나,
   이미 열려 있다면 새로고침(F5)만 눌러주세요.
   방금 추가한 그림이 화면에 나타나요.

4) 인터넷에도 올리기
   컴퓨터에서만 확인했다면 아직 인터넷 주소
   (julyjunghoon.github.io/sunyul-art-graph)에는 반영 안 돼요.
   Claude에게 "업데이트했어, 사이트에도 올려줘"라고 말하면
   나머지는 알아서 해줘요.

파일 이름 짓는 방법 (선택 사항)
--------------------------------
파일 이름이 그대로 그림 제목과 날짜가 돼요. 두 가지 방식을 써요.

  1. 날짜_제목.jpg  (추천)
     예) 20260301_인어공주.jpg   → 날짜: 2026.03.01, 제목: 인어공주
     앞의 8자리 숫자(YYYYMMDD)를 날짜로 읽어요.

  2. 제목_재료.jpg
     예) 무지개_크레파스.jpg     → 제목: 무지개, 재료: 크레파스
     날짜로 시작하지 않으면 밑줄(_) 앞부분을 제목으로 써요.
     이때 날짜는 파일이 저장된(수정된) 날짜가 자동으로 들어가요.

     제목 뒤에 밑줄로 재료를 더 적어도 돼요.
     예) 20260301_인어공주_물감.jpg → 날짜: 2026.03.01, 제목: 인어공주, 재료: 물감

밑줄도 재료도 없으면 재료는 그냥 "그림"으로 표시돼요.

그림을 지우거나 파일 이름을 바꾼 뒤에도 "그림_업데이트.bat"를
다시 실행하면 홈페이지에 그대로 반영돼요.

참고
----
- artworks-data.js 파일은 자동으로 만들어지는 파일이니
  직접 고치지 않아도 돼요 (고쳐도 다음 업데이트 때 덮어써져요).
- 인터넷 주소(julyjunghoon.github.io/sunyul-art-graph)는 이
  컴퓨터의 사진을 직접 읽을 수 없어서 저절로 업데이트되지
  않아요. "업데이트했어, 사이트에도 올려줘"라고 Claude에게
  말해주면 그때 반영돼요.
